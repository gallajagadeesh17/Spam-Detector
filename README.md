# 🚀 About SpamGuard AI

SpamGuard AI is a modern AI-powered email security platform that detects spam and phishing emails using Machine Learning.

The system combines an intelligent spam detection engine with secure Google Authentication, a user-friendly dashboard, detailed scan history, and an enterprise-inspired admin panel.

Built to demonstrate production-level AI application development using Flask, Docker, and Machine Learning.

# 🚀 Quick Start

### Clone Repository

```bash
git clone https://github.com/gallajagadeesh17/Spam-Detector.git
```

```bash
cd Spam-Detector
```

### Install Requirements

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```

---

# 🐳 Docker

Build Image

```bash
docker build -t spam-detector .
```

Run Container

```bash
docker run -p 8080:8080 --env-file .env spam-detector
```
